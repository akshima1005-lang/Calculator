# 🧮 Python Calculator Website

## 📌 Project Description

This project is a simple **Calculator Website** developed using **Python and Flask**. It allows users to perform basic mathematical operations such as addition, subtraction, multiplication, and division through a simple web interface.

This project is suitable for **first-year students** and demonstrates how Python can be used to create a basic web application.

## ✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* User-friendly web interface
* Error handling for division by zero
* Responsive and simple design

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **HTML**
* **CSS**

## ⚙️ Requirements

Before running the project, make sure Python is installed on your computer.

Install Flask using:

```bash
pip install flask
```

## ▶️ How to Run the Project

### Step 1: Open the project in VS Code

Open the `calculator_website` folder in VS Code.

### Step 2: Open the Terminal

In VS Code, go to:

**Terminal → New Terminal**

### Step 3: Install Flask

Run:

```bash
pip install flask
```

### Step 4: Run the Python program

Run:

```bash
python app.py
```

### Step 5: Open the website

After running the program, you will see an address similar to:

```text
http://127.0.0.1:5000
```

Open this address in your web browser.

## 🧮 How to Use

1. Enter the first number.
2. Enter the second number.
3. Select an operation.
4. Click **Calculate**.
5. The result will be displayed on the webpage.

## 📷 Example

```text
        Simple Calculator

   Enter first number
   [       10        ]

   Enter second number
   [        5        ]

   [ Addition (+) ▼ ]

       [ Calculate ]

        Result: 15
```
